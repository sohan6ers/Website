# Professional webpage (static)

This is a single-page, shareable professional profile site for **Sohan Pujar**.

## Quick start

- Open `index.html` in a browser (double-click it).
- Edit `index.html` to tweak wording, add links, or adjust sections as needed.

## Add your résumé PDF (optional)

If you want the “Download résumé” button to work, place a PDF next to `index.html` named:

- `Sohan_Pujar_Data.pdf`

## Deploy options

### GitHub Pages

1. Put these files into a repo (for example, `sohan-pujar.github.io`).
2. In GitHub: **Settings → Pages**.
3. Set **Source** to the default branch and root folder.

### Netlify / Vercel

- Create a new site from the repo.
- Set build to **none** (static).
- Publish directory: the repo root.
